# sdk/typescript

Official TypeScript client SDK for Porichoy. See
[`wiki/TECHNICAL_DESIGN.md`](../../wiki/TECHNICAL_DESIGN.md) §7.2 for scope: OAuth2/OIDC
flow integration for apps ("Login with Porichoy"), plus management API convenience
wrappers (role/permission administration), authenticated with the caller's access token.
Also the natural choice for building a custom login/signup UI theme (§1) against the REST
API, since it can run client-side.

Not yet implemented.
